# 规则口径（与 `game-core` 实现一一对应）

本文记录本项目**实际执行**的斗地主规则。所有条目都有对应的单元测试；修改规则必须先改测试。

## 1. 牌与大小

- 54 张：4 花色 × 13 点数 + 小王 + 大王。
- 大小：`3 < 4 < … < K < A < 2 < 小王 < 大王`。
- 花色不参与比较；同一手牌中不存在两张完全相同的牌。
- 线上编码：`code = rank.value * 10 + suit.ordinal`。

| Rank | 3..A | 2 | 小王 | 大王 |
|---|---|---|---|---|
| value | 3..14 | 15 | 16 | 17 |

## 2. 牌型

| 牌型 | 张数 | 说明 |
|---|---|---|
| 单张 SINGLE | 1 | |
| 对子 PAIR | 2 | 同点 |
| 三张 TRIPLE | 3 | 同点 |
| 三带一 TRIPLE_ONE | 4 | 三张 + 任意单张 |
| 三带二 TRIPLE_TWO | 5 | 三张 + 任意对子 |
| 顺子 STRAIGHT | ≥5 | 连续单张，最大 A；2/王不入顺 |
| 连对 DOUBLE_STRAIGHT | ≥6 且偶数 | ≥3 个连续对子，最大 A |
| 飞机 AIRPLANE | 3n（n≥2） | n 个连续三张，最大 A |
| 飞机带单 AIRPLANE_WINGS / SINGLE | 4n | n 个连续三张 + n 张任意单牌 |
| 飞机带对 AIRPLANE_WINGS / PAIR | 5n | n 个连续三张 + n 个对子（点数互异） |
| 四带二 FOUR_TWO | 6 | 四张同点 + 任意两张单牌（允许一对） |
| 四带两对 FOUR_TWO_PAIR | 8 | 四张同点 + 两个不同点数的对子 |
| 炸弹 BOMB | 4 | 四张同点 |
| 王炸 ROCKET | 2 | 小王 + 大王 |

约定俗成的边界：

- 飞机带单的翅膀可以是任意 n 张牌（允许把一对拆成两张单牌）。
- 四带二的两张单牌允许是一对；不允许把王炸拆成两张单牌来带（实现里不额外禁止，但通常不会这么打）。
- 四带两对要求两个对子点数不同；`3333 9999` 不合法。
- 纯飞机优先于“三张 + 三张当翅膀”的解释：`333444555666` 是 4 连飞机，不是飞机带 3 单。

## 3. 比牌

`canBeat(new, last)`：

1. 没有上家牌 → 任意合法牌型都能出（领出）。
2. 王炸 > 所有非王炸；王炸不能压王炸。
3. 炸弹 > 所有非炸弹非王炸；炸弹之间比点数。
4. 非炸弹之间必须**同牌型、同连数、同翅膀类型、同张数**，再比 `mainRank`。
5. 其余情况一律不能压。

因此：

- 5 张顺子不能压 6 张顺子；
- 飞机带单不能压飞机带对；
- 对子不能压单张。

## 4. 发牌与叫分

- 洗牌：自研确定性 LCG + Fisher–Yates，seed 可复现（用于复盘/测试）。
- 17 / 17 / 17 + 3 张底牌。
- 叫分顺序：每局轮换首家（`round % 3`）。
- 每家一次机会，可叫 1/2/3 或“不叫”；
  - 叫分必须严格高于当前最高分；
  - 叫 3 分立即成为地主并结束叫分；
  - 三家动作完成且最高分 > 0 → 最高叫分者当地主；
  - 三家全部不叫 → 自动用 `seed + 1` 重新发牌（`round + 1`）。
- 地主拿走 3 张底牌，手牌 20 张，先出。

## 5. 倍数与结算

初始倍数：

```
multiplier = 最高叫分(1..3) × (底牌含王 ? 2 : 1)
```

局内翻倍：

- 经典模式：每打出一个炸弹或王炸：`multiplier ×= 2`。
- 天地癞子模式：按软炸/硬炸/癞子炸阶梯翻倍，见第 8 节。
- 春天（地主胜且两个农民一手未出）：`multiplier ×= 2`。
- 反春天（农民胜且地主只出过一手）：`multiplier ×= 2`。

结算（零和）：

```
地主： ± 2 × multiplier
农民： ∓ 1 × multiplier
```

例如：叫 3 分、底牌无王、双方各打一个炸弹、地主春天胜：
`multiplier = 3 × 2 × 2 = 12`，地主 `+24`，两个农民各 `-12`。

## 6. 出牌状态机

- 只有当前 `currentSeat` 能行动。
- 领出时不能“不要”。
- 连续两家“不要”后清空 `lastHand`，由最后出牌者重新领出。
- 出完手牌立即进入 `SETTLING`，同时计算结算。
- 超时托管（规则层兜底，非 AI）：
  - 叫分阶段 → 不叫；
  - 出牌阶段且领出 → 出最小单张；
  - 出牌阶段且跟牌 → 不要。
- 真正的掉线托管由 Host 注入启发式 AI，不改变 reducer 的纯函数性质。

## 7. 座位

- 固定 3 个座位（0/1/2），座位 0 为房主。
- 农民之间是队友；地主是两名农民的对手。
- 座位号决定出牌顺序：`0 → 1 → 2 → 0`。

## 8. 天地癞子（v1.1+）

### 8.1 癞子的确定

- **天癞子**：发牌前用种子确定性随机选一个普通点数（3..2），该点数的 4 张牌全部成为癞子。
- **地癞子**：地主确定后，再从剩余普通点数中选一个；该点数的 4 张牌成为癞子。
- 一局共 8 张癞子；天/地癞子的使用方式相同，区别只在确定时机。
- 癞子可以代替任意**非王**点数，也可以按原点数使用；不能代替小王/大王，不能组成王炸。
- 底牌、手牌中的癞子牌在 UI 上用金色「癞」角标高亮。

### 8.2 炸弹与大小

| 牌型 | 组成 | 说明 |
|---|---|---|
| 硬炸 | 4 张同点数、全部非癞子 | 经典四张炸 |
| 软炸 | ≥4 张，含 1..8 张癞子 + ≥1 张同点数非癞子 | 最大 12 张 |
| 纯癞子炸 | ≥4 张全部为癞子 | 可天/地混合 |
| 王炸 | 小王 + 大王 | 最大 |

比较顺序：

```
4 软炸 < 4 硬炸 < 4 癞子炸 < 5 软炸 < 5 癞子炸 < … < 12 软炸 < 王炸
```

- 先比张数；张数相同再比类型：软炸 < 硬炸 < 纯癞子炸；同类型比点数。
- 硬炸/软炸的点数取非癞子牌的点数；纯癞子炸取实际癞子牌的最大印刷点数。
- 任何炸弹都大于普通牌型；王炸大于所有其他牌。

### 8.3 倍数

| 出牌 | 倍数 |
|---|---|
| 4 张软炸 | ×2 |
| 4 张硬炸 / 纯癞子炸 | ×4 |
| 5 张及以上任意炸弹 | ×6 |
| 王炸 | ×6 |

叫分、底牌含王、春天/反春天、结算比例与经典模式一致。

### 8.4 出牌识别

- 选择牌组后，解析器会自动尝试所有癞子分配，返回**最强合法解释**。
- 例如选中 `333 + 5(癞子)` 会被识别为 3333 软炸，而不是三带一。
- 癞子可以补顺子、连对、飞机、三带、四带二；补齐时不能出现王。
- 每个动作仍然只由 `GameRules.reduce` 校验，客户端 UI 不重算规则。
